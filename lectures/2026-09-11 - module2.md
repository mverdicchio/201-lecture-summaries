## While Loops

A **while loop** is a sentinel loop — it keeps running until a condition becomes false.

```python
while <boolean expression>:
    # body — must eventually make the condition false
```

If the body never makes the condition false, you get an **infinite loop**. Break out with **Ctrl+C**.

### Counting down (avoid this pattern)

```python
i = 3
while i != 0:
    print("meow")
    i -= 1
```

### Counting up (preferred)

```python
i = 0
while i < 3:
    print("meow")
    i += 1
```

Count from 0 upward — that's the CS convention. Using `<` instead of `!=` also guards against accidentally skipping the target value.

### Shortcut assignment operators

| Long form | Short form |
|-----------|-----------|
| `i = i + 1` | `i += 1` |
| `i = i - 1` | `i -= 1` |
| `i = i * 2` | `i *= 2` |
| `i = i / 2` | `i /= 2` |

Python does **not** have `++` or `--` (unlike C, C++, Java). Use `+= 1`.

## For Loops

A **for loop** iterates over a list a fixed number of times.

```python
for i in [0, 1, 2]:
    print("meow")
```

### `range()`

`range(n)` generates a sequence of `n` integers from 0 to n−1 — no need to write the list manually:

```python
for i in range(3):
    print("meow")
```

### When to use which

- **while loop** — unknown number of repetitions (e.g., input validation)
- **for loop** — known number of iterations

### Unused loop variable

If you don't use the counter inside the body, replace it with `_` to signal that to readers:

```python
for _ in range(10):
    print("meow")
```

## `break` and `continue`

- `break` — exits the loop immediately
- `continue` — skips the rest of the body and jumps back to the top of the loop

### Input validation pattern

```python
while True:
    n = int(input("Enter a non-negative number: "))
    if n >= 0:
        break
```

`while True` creates an intentional infinite loop; `break` is the only exit. The user is trapped until they comply.

### Modular version

```python
def get_number():
    while True:
        n = int(input("Enter a non-negative number: "))
        if n >= 0:
            return n

def meow(n):
    for _ in range(n):
        print("meow")

def main():
    meow(get_number())

main()
```

Inside a function, `return` stops the loop the same way `break` does — and also hands back the value.

## Lists (intro)

A **list** is a data structure that holds multiple values.

```python
my_data = [2, 4, 6, 8, 10]
```

- Indexed starting at **0**
- `my_data[1]` → `4`
- `my_data[-1]` → `10` (last item — negative indexing works from the right)
- `len(my_data)` → `5`
- Can hold mixed types (strings, ints, floats, booleans)

### Iterating over a list

```python
names = ["Harry", "Hermione", "Ron"]
for name in names:
    print(name)
```

Convention: list name is plural (`names`), loop variable is singular (`name`).

## Extras

**String multiplication:**
```python
print("meow" * 5)    # meowmeowmeowmeowmeow
print("meow\n" * 5)  # five meows on separate lines
```

**Slowing down a loop:**
```python
import time
for _ in range(10):
    print("meow")
    time.sleep(0.5)
```
